# C++ Algorithms

👋 **About This Repository**

A collection of classic algorithms and problem-solving exercises 
implemented in C++. The focus is on building strong fundamentals 
through hands-on practice. Each algorithm includes a flowchart 
for better understanding.

**Level:** Beginner  
**Focus:** Core algorithms and problem-solving  
**Code:** VS Code + MinGW g++  
**Flowcharts:** Flowgorithm  
*Note:* Some algorithms (matrices, recursion) don't have 
flowcharts because Flowgorithm doesn't support 
2D arrays or recursive calls.

---

## 📚 Topics Covered

- Basic Algorithms (max, min, sum, average, prime)
- Loop-based Algorithms
- Array Operations
- Sorting Algorithms
- Searching Algorithms
- Matrix Operations
- Recursion

---

## 📂 Repository Structure

```bash
cpp-algorithms/
├── README.md
├── basic-algorithms/          # Max, min, sum, average, prime
├── loop-algorithms/           # Sum-average, salary, tax

├── searching/                 # Linear, binary
```

## 🚀 How to Run

- Open any `.cpp` file in VS Code
- Press `Ctrl + Alt + N` to run (using Code Runner)
- Or `Ctrl + Shift + B` to build
